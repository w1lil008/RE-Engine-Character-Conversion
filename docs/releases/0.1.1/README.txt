BELA FOR GRACE - EXPERIMENTAL v0.1.1

This is a COMPLETE mod. It contains all 80 native assets; v0.1.0 is not required.
Do not enable v0.1.0 and v0.1.1 together.

CHANGE
Covered rear/side hair uses hood-derived weights to reduce hair passing through
the hood during ADS. Only the two native hair variants differ from v0.1.0.
Geometry, materials, textures, Grace's rig and other body/clothing weights stay
the same. No new physics or facial animation is included.

EVIDENCE
The user has confirmed v0.1.0's standing assembly, weapon handling and one
cutscene's appearance/lighting. This v0.1.1 revision has NOT been tested in-game.
The reopened native hair correction was reviewed in eight synthetic Blender
head/chest poses. One residual card-overlap diagnostic remains unclassified;
this is not a collision-free claim. The included screenshot is from v0.1.0.

INSTALL
1. Exit RE9.
2. Put this ZIP into Fluffy's Games/RE9/Mods folder and refresh the mod list.
3. Disable 'Bela for Grace - Experimental v0.1.0'.
4. Enable 'Bela for Grace - Experimental v0.1.1'.
5. Use Grace's default outfit with Hair Strands OFF. Keep GraceBun disabled.
6. Restart the game. Existing REFramework loose-file/texture loading is needed.

TEST
Repeat the same over-shoulder handgun ADS view that showed the right hood issue.
Aim up/down and turn both ways; check rear hair, hood coverage and front locks.
Repeat the tested cutscene to check headwear and lighting.
Then walk/turn, crouch, use stairs and check feet/skirt contact.
First-person arms, firing/reload/holster, interactions, damage and other scenes
remain separate test obligations unless specifically confirmed.

KNOWN LIMITS
Neutral face: no expression, lip-sync or eye-motion retargeting yet.
Hair has no Bela collision simulation. Dress uses skinning, not native cloth.
Small cloth creases/clipping remain possible. Grace's boots are retained.
Bela's authentic heels, decorative stitches and animated cape are omitted.
Other outfits and dedicated cutscene/damage variants are not fully covered.

ROLLBACK
Exit the game, disable v0.1.1, then re-enable v0.1.0 through Fluffy if needed.
Report the exact action/camera and a screenshot/clip; preserve REFramework logs
for crashes or loading failures. Official game archives are not replaced.

Built from legitimately owned local game installations. Keep this prototype local.
