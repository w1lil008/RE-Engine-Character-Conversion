BELA FOR GRACE - EXPERIMENTAL v0.1.2

COMPLETE standalone mod: all 80 native assets. No previous version is required.
Enable only one Bela for Grace version at a time.

CHANGE
Extends hood-derived hair weights onto the lower forward locks missed by v0.1.1.
Distance fade retains hair farther from the hood. Hair positions and topology
are unchanged; no cards were deleted or shrunk. Only two native hair variants
differ. Body/clothing/face/boots, materials, textures, Grace's 611-bone hierarchy
and bind matrices are unchanged. No new physics or facial animation is included.

EVIDENCE AND LIMITS
User-run v0.1.0 tests confirmed standing appearance, weapon handling and one
cutscene's appearance/lighting. The user tested v0.1.1 ADS: clipping was slightly
less obvious but remained. All 80 installed files matched v0.1.1.
v0.1.2 has NOT been tested in-game.

The expanded checks include every hair card and 14 synthetic head/chest/arm/
shoulder poses. Reopened-native BVH overlap diagnostics fell from 257 to 13
hair triangles in the raised-shoulder fixture; 8 remain at rest in both versions.
These counts ignore alpha and do not establish visible or collision-free motion.
Six native front/rear renders were reviewed without an obvious new major
attachment failure. A 34-object audit retains all non-hair geometry and weights.
Earlier 14 joint fixtures still apply to the unchanged body/clothing assembly.
The included thumbnail is from the user's v0.1.0 cutscene, not this revision.

INSTALL
1. Exit RE9.
2. Put this ZIP in Fluffy's Games/RE9/Mods folder and refresh the list.
3. Disable older Bela for Grace versions, including v0.1.1.
4. Enable 'Bela for Grace - Experimental v0.1.2'.
5. Use Grace's default outfit with Hair Strands OFF. Keep GraceBun disabled.
6. Restart RE9. Existing REFramework loose-file/texture loading is required.

RETEST
Repeat the same over-shoulder ADS view with the right lower lock visible.
Aim up/down and turn both ways; check the hood back, sides and front locks.
Repeat the tested cutscene: lower locks now follow more hood/shoulder motion,
so check them during head turns and dialogue.
Then walk/turn, crouch, use stairs and inspect skirt and feet/floor contact.
Specific firing/reload/holster, first-person arms, interactions, damage and other
weapons/scenes/outfits remain separate checks unless specifically confirmed.

KNOWN LIMITS
Neutral face: no expression, lip-sync or eye-motion retargeting yet.
Hair has no Bela collision simulation. Dress uses skinning, not native cloth.
Small cloth creases/clipping remain possible. Grace's boots are retained.
Bela's authentic heels, decorative stitches and animated cape are omitted.
Other outfits and dedicated cutscene/damage variants are not fully covered.

ROLLBACK
Exit RE9, disable v0.1.2, then re-enable v0.1.1 through Fluffy if needed.
Report action/camera and an image/clip; retain REFramework logs for load failures.
The project has not installed this build or changed official game archives.
Built from legitimately owned local installations. Keep this prototype local.
